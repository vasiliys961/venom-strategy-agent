# VENOM Strategy Agent

Telegram-ассистент по личной стратегии на основе фреймворка **VENOM** из книги
Семёна Колосова «Стратегия без иллюзий» (Альпина ПРО, 2026).

## быстрый старт для пользователя (без программирования)

**если вы просто хотите запустить готового бота — читайте [`HOW_TO_USE.md`](./HOW_TO_USE.md).**
там пошаговая инструкция на русском: как скачать репозиторий, получить токен
Telegram-бота, настроить и запустить всё одной командой через Docker.

Нейросеть подключена через **Polza.ai** — российский агрегатор LLM-моделей
(Claude, GPT, Gemini и др.), доступный из РФ без VPN, с оплатой в рублях.

## идея метода

VENOM — метод, который проводит человека через 5 этапов:

1. **V**ision — образ желаемого будущего (горизонт 10 лет)
2. **E**valuation — анализ текущего состояния (сферы жизни, сильные/слабые стороны, окружение)
3. **N**arrow gaps — стратегические разрывы устойчивости и развития
4. **O**bjectives — стратегические цели и их декомпозиция (SMART)
5. **M**anagement — операционная система: таск-менеджермент, привычки, ретроспектива, обучение

ассистент реализован не как линейный опросник, а как **граф состояний**
(LangGraph): каждый этап — отдельный узел со своей Pydantic-схемой вывода,
между этапами передаётся накопленный `VenomCanvas`. Отдельный
Reflection-узел умеет возвращать пользователя к предыдущим этапам, если
новые ответы меняют картину — это соответствует духу метода (цикл, а не
разовое упражнение).

## архитектура

```
telegram user <-> aiogram bot <-> LangGraph agent <-> LLM (Polza.ai: Claude/GPT/Gemini)
                                        |
                                   SQLite (VenomCanvas state)
```

## структура репозитория

```
src/
  state.py       - Pydantic-модель VenomCanvas и состояние графа
  prompts.py     - системные промпты для каждого этапа (Socratic questioning)
  graph.py       - LangGraph: узлы этапов + reflection-роутер
  storage.py     - персистентность Canvas (SQLite по умолчанию)
  bot.py         - Telegram-интерфейс (aiogram)
  main.py        - точка входа
requirements.txt
.env.example
Dockerfile
docker-compose.yml
HOW_TO_USE.md    - подробная инструкция для конечного пользователя
```

## запуск для разработчика (без Docker)

1. `pip install -r requirements.txt`
2. скопируйте `.env.example` в `.env`, укажите `TELEGRAM_BOT_TOKEN` и
   `POLZA_API_KEY` (сервис polza.ai — доступен из РФ без VPN, оплата рублями).
3. `python -m src.main`

## запуск через Docker (рекомендуется для конечных пользователей)

```bash
cp .env.example .env
# заполните .env своими токенами
docker compose up --build
```

## экспорт результата

по завершению всех этапов бот собирает финальный **VENOM Canvas** и
отправляет пользователю как текстовый отчёт — карту личной стратегии
с целями, разрывами и планом на первые 30 дней.
