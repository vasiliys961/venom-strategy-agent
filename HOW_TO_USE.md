# Как пользоваться VENOM Strategy Agent (простая инструкция)

Эта инструкция для тех, кто **не программист**, но хочет запустить своего
личного ассистента по стратегии на основе метода VENOM
(книга Семёна Колосова «Стратегия без иллюзий»).

Есть два способа запуска: через **Docker** (проще, рекомендуется) и
**вручную через Python** (если Docker не хочется ставить).

Ассистент работает из России без VPN — нейросеть подключена через
российский сервис **Polza.ai**, который даёт доступ к Claude, GPT и другим
моделям с оплатой в рублях.

---

## Способ 1: через Docker (рекомендуется)

### шаг 0. скачайте репозиторий

На странице репозитория на GitHub нажцмите зелёную кнопку **Code → Download ZIP**,
распакуйте архив в любую папку на компьютере.

Либо, если у вас установлен git:
```bash
git clone <ссылка на репозиторий>
cd venom-strategy-agent
```

### шаг 1. установите Docker

скачайте и установите Docker Desktop: https://www.docker.com/products/docker-desktop/
(есть версии для Windows, macOS, Linux). После установки просто откройте
приложение Docker Desktop один раз — оно должно показать "Running".

### шаг 2. получите токен Telegram-бота

1. Откройте Telegram, найдите бота **@BotFather**.
2. Напишите ему `/newbot`.
3. Придумайте имя и username для своего бота (username должен заканчиваться на `bot`).
4. BotFather пришлёт вам токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   сохраните его.

### шаг 3. получите ключ Polza.ai (доступ к нейросети)

1. зарегистрируйтесь на https://polza.ai (без VPN, доступно из россии).
2. в личном кабинете https://polza.ai/dashboard пополните баланс рублями
   (для теста хватит 300-500 рублей).
3. скопируйте свой API-ключ в личном кабинете.

### шаг 4. настройте файл .env

в папке проекта найдите файл `.env.example`, сделайте его копию с именем `.env`
и заполните двумя строками:

```
TELEGRAM_BOT_TOKEN=вставьте_сюда_токен_из_шага_2
POLZA_API_KEY=вставьте_сюда_ключ_из_шага_3
```

остальные строки можно не трогать — там уже стоят рабочие значения по умолчанию
(модель `anthropic/claude-sonnet-5`). если хотите другую модель — посмотрите
список доступных на https://polza.ai/models и замените значение `LLM_MODEL`.

### шаг 5. запустите

откройте терминал (Windows: PowerShell, macOS: Terminal) в папке проекта и выполните:

```bash
docker compose up --build
```

дождитесь строки `Start polling` в логах — это значит, бот запущен.
откройте своего бота в Telegram и напишите `/start`.

### остановка

чтобы остановить бота: нажмите `Ctrl+C` в терминале, затем `docker compose down`.

## способ 2: вручную через Python (без Docker)

### требования

установленный Python версии 3.11 или выше: https://www.python.org/downloads/
при установке на Windows обязательно поставьте галочку **Add Python to PATH**.

### шаги

```bash
cd venom-strategy-agent
python -m venv .venv

# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

дальше — те же шаги 2-4 из способа выше (токен бота, ключ Polza.ai, файл `.env`).

запуск:
```bash
python -m src.main
```

## как пользоваться самим ассистентом

1. Найдите вашего бота в Telegram и напишите `/start`.
2. бот проведёт вас через 5 этапов метода VENOM:
   - **Vision** — образ желаемого будущего через 10 лет
   - **Evaluation** — честный анализ текущей жизни по сферам
   - **Narrow gaps** — что мешает устойчивости и развитию
   - **Objectives** — стратегические цели в формате SMART
   - **Management** — как отслеживать прогресс и держать привычки
3. отвечайте развёрнуто — ассистент задаёт уточняющие вопросы, если ответ
   слишком короткий или общий.
4. в конце бот присылает готовый **VENOM Canvas** — итоговую карту вашей
   личной стратегии в виде текста, который можно сохранить или распечатать.
5. если захочете начать заново — команда `/start` сбросит прогресс.

## частые проблемы

| Проблема | решение |
|---|---|
| бот не отвечает | Проверьте, что в `.env` правильно вставлен `TELEGRAM_BOT_TOKEN`, без пробелов |
| ошибка про Polza / 401 Unauthorized | проверьте `POLZA_API_KEY` и баланс в личном кабинете polza.ai |
| `docker compose` — command not found | обновите Docker Desktop до последней версии, там команда `docker compose` (без дефиса) встроена |
| бот отвечает не по-русски / странно | модель можно сменить в `.env` через `LLM_MODEL`, например на `openai/gpt-4o` (см. список на polza.ai/models) |

## стоимость

сам бот бесплатен (открытый код). платите только за использование нейросети
через Polza.ai — оплата рублями, обычно это несколько рублей за один диалог
при работе с моделями уровня Claude Sonnet.
